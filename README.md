# ことばでタッチ！ — PWA版

iPadなどで「大きい・小さい」「多い・少ない」「長い・短い」を学ぶタッチ式WEBアプリです。

## iPadでホーム画面に追加する方法

1. PWAをHTTPS対応のWEBサーバーに配置し、iPadのSafariで開きます（公開済みサイトのURLからも使えます）。
2. アプリの初回読み込みが終わるまでオンラインで開いておきます。
3. Safariの「共有」→「ホーム画面に追加」を選びます。
4. ホーム画面の「ことばタッチ」アイコンから起動します。

初回のオンライン読み込みとキャッシュ作成が完了すると、問題・イラスト・正解時のアニメーション・メロディーはオフラインでも利用できます。読み上げ音声はiPad本体の日本語音声機能に依存します。

## ZIPを自分で設置する場合

- ZIPを解凍し、`index.html` と同じ階層にある全ファイル・`icons/` フォルダを保ったまま、HTTPS対応の静的WEBサーバーにアップロードしてください。
- PWAのインストールとService Workerによるオフライン機能は、HTTPSまたは開発用localhostから開いた場合に動作します。`file://` で直接開いた場合はPWAとしてインストールできません。
- アプリは外部のライブラリ・画像・音声ファイルを使いません。正解時の音は端末内で生成します。個人情報や学習履歴はサーバーに送信しません。
- 公開済みのサイトが非公開設定の場合は、最初にログインしてページを開く必要があります。

## ファイル一覧

| ファイル | 内容 |
| --- | --- |
| `index.html` | アプリの画面 |
| `app.js` | 問題・操作・音声・アニメーションの処理 |
| `style.css` | iPadに対応したデザイン |
| `manifest.webmanifest` | PWAの名前・起動方法・アイコン定義 |
| `sw.js` | オフライン利用のためのキャッシュ処理 |
| `icons/` | ホーム画面用アイコン |
